Images for Flying Friends.

mia.png          the obstacle: every pillar in the game is built from this cutout.
                 Missing file -> patterned generated pillars.

Optional scene art (transparent PNG where noted). Missing files use generated art.
background.png  full sky image, scaled to cover the screen (no scrolling)
clouds.png      transparent strip, tiles horizontally, scrolls slowly (drawn 240 tall)
buildings.png   transparent skyline strip, tiles horizontally, medium speed (230 tall)
ground.png      road strip, tiles horizontally, fastest (drawn 96 tall)

Character cutouts live in assets/characters/ and are shown on the selection
cards and as the player sprite.

Tileable strips must be seamless left to right.
Icons (sound, pause) are inline SVG in index.html; edit them there.
